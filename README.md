# periodic_table
3D periodic table of elements

公開ページ: https://supergenom.github.io/periodic_table/

## データの出典とライセンス
- 元素の詳細情報（`element-details.js`）は Wikipedia日本語版 各元素記事の情報ボックスをもとにしており、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/deed.ja) で提供されます。
- 殻ごとの電子数（`element-shells.js`）は [PubChem](https://pubchem.ncbi.nlm.nih.gov/periodic-table/) の周期表データから計算しています。
